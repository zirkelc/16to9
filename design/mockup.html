2 · Ratio fit: the smallest change

Example: Safari is 1512 × 945 pt and you select 16:9. The app calculates two candidates and picks the one that changes the window less.

  1. Calculate both candidates: keep the width, or keep the height. Round to whole pixels.
  2. Pick the candidate with the smaller change in points. A setting can force “keep width” or “keep height”.
  3. If it does not fit the visible screen area (no menu bar, no Dock), use the other one.
  4. If neither fits, make the window as large as possible with the ratio.
  5. Keep the top-left corner. Move the window only if it goes off the screen.
  6. Read the size back. Some apps have a minimum size or size in steps (Terminal). Then try the other candidate and show the real result.

3 · Guide overlay with rulers

Select “Show guide” and a preset, for example 1920 × 1080 px. A frame with rulers shows on the screen. Move and resize the window by hand. Each edge turns green when it matches, and orange with the difference when it does not. “Snap” fits the window in one click. The overlay does not catch clicks, and it is hidden from screenshots.

Rulers count from the top-left corner of the frame, in the selected units. The four thin lines continue the frame edges over the full screen, like guides in Photoshop. Drag a corner handle to move the frame. The live readout needs the Accessibility permission. Without it, the frame and rulers still work.

6 · First start and feedback

macOS asks the user one time for Accessibility access. Without it, the app cannot move other windows. After each resize, a small toast shows the real result and an undo action.

Allow window control

To resize windows of other apps, macOS needs your permission. You do this one time.

  1. Click “Open System Settings”.
  2. Turn on Window Resizer in Accessibility.
  3. Come back. The app finds the change.
