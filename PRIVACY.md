# 16to9 privacy policy

16to9 does not collect, store or send personal data.

- The app has no analytics and no tracking.
- The only network access is the check for updates. It loads the update list from GitHub Pages (`zirkelc.github.io`), and an update downloads from GitHub Releases (`github.com`). The request contains the name and version of the app, and GitHub sees your IP address, as with any download. You can turn off automatic checks in Settings › About.
- The app reads the position and size of the front window, only to resize it or to compare it with the guide. It does not read window contents.
- Your settings and presets stay on your Mac, in the settings of the app.

Questions: open an issue at https://github.com/zirkelc/16to9/issues.
